## Adding a New Example

Create `examples/[song-slug].md` with this structure:

```markdown
# Example: [Song Title]

**Genre:** [genre]
**Rating:** ⭐⭐⭐⭐
**Date:** YYYY-MM-DD
**Suno version:** v5

## Prompt

### Title
[Song title as entered in Suno]

### Style Block
[Full style/genre/mood text]

### Lyrics
[Full lyrics with metatags]

### Slider Settings
| Slider | Value |
|--------|-------|
| Creativity | X |
| Clarity | X |

## Outcome Notes
What Suno produced. What worked, what didn't.

## Lessons
- Takeaway 1
- Takeaway 2
```
